# ArkanDigital

A full-stack digital marketplace application built with modern web technologies.
The project focuses on scalable frontend architecture, responsive UI,
product management, and backend integration.

---

## ✨ Features

- 🛒 Product management
- 🔐 User authentication
- 👤 User management
- 📱 Responsive user interface
- 🎨 Reusable UI components
- 📦 API-based data handling
- 🗂️ Database integration

---

## 🛠️ Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- Redux Toolkit
- React Query

### UI & Styling

- Material UI
- Headless UI
- Styled Components
- Framer Motion

### Backend

- Node.js
- MongoDB
- Mongoose

### Authentication & Security

- JWT Authentication
- bcrypt

---

## 🚀 Installation

Clone the repository:

```bash
git clone <repository-url>

cd ArkanDigital
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
